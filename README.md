# Resume Website

Personal resume website for Siddhanth Hariramani — VP Marketing · Brand & Growth · Digital P&L Owner.

🔗 **[siddhanthresume.netlify.app](https://siddhanthresume.netlify.app)**

---

## What's in it

- Animated hero with Three.js particle system
- Live counters for key metrics
- Full experience, skills, brands, and tech stack sections
- Downloadable ATS-friendly PDF CV
- Fully responsive, mobile-optimised
- Paterson Capital colour system (Navy `#19426E` + Amber `#D4903A`)

---

## Built with

Plain HTML, CSS, and vanilla JavaScript. No framework. Deployed on Netlify.
